# Miya 小手机

浏览器里的沉浸式「小手机」前端：杂志风多页桌面、AI 对话、情侣玩法、深入系统模拟，以及一整套可本地美化的应用壳。

本仓库无登录门槛，打开即可进入桌面。数据默认保存在浏览器本地（`localStorage` / IndexedDB / OPFS 等）。

许可协议：[GNU Affero General Public License v3.0](./LICENSE)（AGPL-3.0）。

## 功能概览

### 桌面与系统壳

- **四页杂志风主屏**：手帐 / 底片匣 / 侧写 / 雾笺等排版，可分页滑动
- **自定义桌面**：4×7 图标网格、长按拖动排序、小组件库与实例级配置
- **美化中心**：壁纸、图标、字号、桌面挂件、锁屏壁纸与四位密码
- **启动页 / 锁屏 / 状态栏**：开屏动画、可选锁屏、手机态与网页态切换
- **PWA**：`manifest.json` + Service Worker，可「添加到主屏幕」类 App 使用
- **导入导出**：设置内支持轻量 ZIP 备份（对话、设置、深入、主题等）

### 核心互动

| 模块 | 说明 |
|------|------|
| **聊天** | 多联系人会话、群聊、红包、朋友圈、相册、钱包、语音/通话 UI、心声、情诗、翻译、记忆抽取、后台消息与感知规则等；支持联系人全局最高优先级提示词 |
| **世界书** | 全局 / 线上 / 线下范围匹配；关键词触发；可绑定到联系人 |
| **联系人** | 角色档案、关系与聊天默认设置；可设置关于该联系人的全局最高优先级 system 提示词 |
| **记忆** | 长期记忆相关入口与管理 |
| **论坛** | 可配置独立论坛 API（留空则沿用对话 API） |
| **音乐** | 播放器 UI、桌面歌词、**一起听** |
| **打字机** | 共读 / 器物等叙事向写作玩法 |
| **模拟器** | AI 叙事模拟器（独立模式层） |
| **日记** | 日记与定时相关能力 |
| **情侣空间** | 打卡、时间线、悄悄话、相册板等 |
| **行程轨迹** | 行程记录与展示 |
| **深入** | 模拟微信 / 短信 / 小红书 / 抖音 / B 站 / 小说 / 备忘 / 健康 / 待办 / 游戏 / 云盘 / 相册 / 浏览器 / 外卖 / 购物等「深层 App」 |
| **线下 / 便利店 / 赛事 / 剧场 / 天气** 等 | 桌面磁贴入口的玩法与场景应用 |
| **74 号便利店、错位时空、共鸣、记录** 等 | 扩展玩法入口（部分为场景化 UI） |

> 部分桌面磁贴（如「大世界」）仍可能标注为开发中，以实际页面提示为准。

### 技术特点

- 静态前端：HTML / CSS / 原生 JavaScript，无构建步骤
- 按需懒加载非聊天模块（见 `js2/miya-lazy-boot.js`），减轻首屏压力
- 移动端视口与 iOS 键盘高度做了专门处理

## 环境要求

- 现代浏览器（推荐最新版 Chrome / Edge / Safari / Firefox）
- 本地预览需要任意静态文件服务器（因部分能力依赖 `http(s)://`，不建议用 `file://` 直接打开）
- 使用 AI 对话等功能时，需在应用 **设置** 中自行填写可用的 API 地址与密钥（本仓库不包含任何第三方密钥）

## 快速开始

### 1. 克隆仓库

```bash
git clone https://github.com/lixooo00-lab/mingruis-miya.git
cd mingruis-miya
```

### 2. 启动本地静态服务

任选一种即可。

**Python 3：**

```bash
python3 -m http.server 8080
```

**Node.js（需已安装 `npx`）：**

```bash
npx --yes serve -l 8080
```

**PHP：**

```bash
php -S 127.0.0.1:8080
```

### 3. 打开页面

浏览器访问：

```text
http://127.0.0.1:8080/
```

首次进入会看到启动页，随后进入桌面。在 **设置** 中配置对话 / 论坛 / 生图等 API 后，即可使用聊天与相关 AI 能力。

### 手机预览

同一局域网下，用电脑的局域网 IP 访问，例如：

```text
http://192.168.x.x:8080/
```

也可部署到任意静态托管（GitHub Pages、Cloudflare Pages、Nginx、对象存储静态站点等）。部署后建议用 HTTPS，以便 PWA / 持久存储等能力更完整。

## 常用操作

| 操作 | 说明 |
|------|------|
| 配置 API | 桌面 → **设置**，填写对话 API；论坛 API 可单独配置 |
| 通知合并与输入交互 | 同一会话 30 秒内的多条新消息会合并为一条系统通知，显示累计条数。聊天输入框已移除 Enter 键直接发送，需点击发送按钮提交；Shift+Enter 仍可换行 |
| 引用协议 | 单聊与群聊引用时，引用行（`引用-原话摘抄`）必须独占一行；摘抄内的任意全角/半角冒号及其它自然标点都属于原话，不是引用与回复的分隔符；回复必须从下一行开始，每条回复各占一行 |
| 心声协议 | 线上单聊每轮末尾的 `<miyavoice>` 段。默认四行为 `好感度`、`欲望值`、`当前状态`、`角色心声`，每行独占一行、行首标签原样保留。`当前状态` 为双模字段：上文已给出明确角色设定时写此刻的动作、神态与环境互动；没有角色设定时写当前对话的状态与走向（话题、节奏、语境变化）。该字段原名 `行为动作`，改名后旧标签在解析、气泡拦截与旧预设剥离处仍被识别，聊天中途切换和历史记录回看都不受影响；存量心声记录不做迁移。启用自定义心声预设后，默认四行整体失效，只按预设字段输出 |
| 设置联系人提示词 | 聊天 → 联系人 → 编辑档案 → **最高优先级提示词**。当 AI 请求代表或涉及该联系人时，内容会原样置于普通提示词之前，覆盖线上聊天、通话、群聊、线下预约、朋友圈角色互动、情侣悄悄话等相关请求。联系人档案是这项提示词的权威来源，保存后会应用到相关请求；清空并保存后旧值不会继续生效，既有联系人数据也可继续使用。普通线上一对一中，如果联系人名称命中项目现有的常见模型名规则，会跳过整个角色档案块，但最高优先级提示词仍会独立保留并正常发送 |
| 线上单聊内置记忆 | 分镜/合卷与线上/线下互通记忆固定在聊天历史之后注入；角色长期记忆分为固定注入与关键词召回，固定记忆不占召回名额，普通记忆按本轮末尾连续用户气泡合并后的完整请求反向匹配已有关键词并最多召回 5 条，无命中时不随机补充。旧角色记忆因没有关键词会继续按固定记忆处理；可在记忆阅览室手动新建、编辑关键词、切换固定状态，或按原聊天范围重新提取正文与关键词。通话和特殊预约模式不随此项改变 |
| 切换联系人对话模式 | 聊天 → 联系人 → 编辑档案 → **对话模式**。默认为 **RP 模式**；其默认运转规则只要求服从实际注入的联系人档案、人设、关系、世界书和当前情境，不预设温柔、友善、活跃、亲密、真人聊天节奏或表达工具偏好。切换为 **本体对话** 后，普通单聊不再常驻注入外卖、送礼、转账、位置、情诗、朋友圈、主动通话等模拟能力提示，并将默认思维链、运转规则与角色心声改为中性表述。用户明确点击情诗、通话等功能时，仍会临时注入完成该界面任务所需的中性提示。自定义思维链、运转规则和心声预设继续优先；内置输出格式、心声完整性、防编造与上下文衔接规则仍会固定后置注入，群聊行为暂不随此开关变化 |
| 联系人设置继承 | 联系人的聊天设置默认继承全局设置；旧联系人或不完整数据没有保存继承标记时，也按继承全局处理。只有明确关闭继承（`useGlobal` 为 `false`）后，才使用该联系人的独立设置 |
| 查看请求预览 | 线上聊天窗口 **+** 工具 → **本轮最后一次实际请求**。预览包含结构视图与完整非敏感 JSON，只保存在本地；不包含 API 地址、API key、请求头或其他认证信息。Token 来源明细是用于理解上下文组成的本地估算，可分别查看联系人最高优先级提示词、旧全局提示词、系统主提示、世界书、联系人档案等来源，字符数按最终实际请求正文统计。多模态内容在统计与本地调试中使用统一文本化口径（图片记为 `[image]`），不会改变发送给 API 的原始多模态内容 |
| 聊天时间与跨段提醒 | 单聊、群聊和线下约会共用固定、不含逐轮动态变量的【时间运转】说明；普通线上一对一不再另行注入【本轮时间】。新消息实际写入时会固定浏览器本地 `createdAt`，并以 `YYYY/MM/DD-星期X-HH:mm:ss` 同时用于界面显示和模型逐条消息前缀；真实消息原有的方括号浏览器本地发送时间戳会保留在消息中。涉及时间、日期、顺序、间隔、时长或时效性时，模型应结合相关消息的时间戳理解，不默认消息发生在刚刚；回复正文不输出时间戳标记，无关时不主动报时或反复强调时长。新实时真实消息还会固定 `conversationGap`；仅当相邻有效消息严格间隔超过 30 分钟时，界面显示跨段分隔，并给模型注入一次时长提醒，不受逐条时间显示开关影响。旧历史不会补写这两个字段。协议清洗会按消息来源处理：用户和系统正文中的合法方括号、旧 `⧗` 文本会保留，模型消息也只移除开头可确认属于协议的时间前缀，避免误删正文中间或不同时间的内容 |
| 备份数据 | 设置内的导入 / 导出（ZIP） |
| 换壁纸图标 | 桌面 → **美化** |
| 自定义布局 | 美化中切换自定义桌面，或主屏编辑小组件 |
| 清缓存异常 | 浏览器清除本站数据，或先注销 SW 后再强刷（开发时常用） |

开发时若改了 `sw.js` 仍看到旧资源，可在开发者工具 → Application → Service Workers 里 unregister，再硬刷新。

## 二次开发提示

- 主入口几乎都在 `index.html`；业务逻辑按模块拆在 `js1/`、`js2/`，样式在 `css/`
- 新增非首屏 App 时，优先挂到 `js2/miya-lazy-boot.js` 的分组懒加载，避免拖慢启动
- 静态资源 URL 带有 `?v=` 版本参数；发版时如有缓存问题，可递增相关版本号
- **不要**把含密钥、用户名单、找回码等私密配置提交进公开仓库
